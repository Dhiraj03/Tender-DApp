1. Install all npm dependencies using npm i.

2. Run the compilation script in order to compile the smart contracts and output (node compile.js)
the JSON interface into the build directory (two files - tender and tenderFactory will be created)

3. Run the deployment script in order to deploy the smart contract to the Ethereum blockchain (node deploy.js)
(Current contract address - 0x72E0F25f3eFBcC07ab8881BE2e8667b7E25b1aC5)

4. Whenever the Infura API URL is changed, change the same in 2 locations - ethereum/web3.js and ethereum/deploy.js

5. After deploying the tenderFactory contract, update the contract address in the ethereum/factory.js 

6. Run the server using 'npm start' command and go to http://localhost:3000 to use the application
